# 자료 출처와 권리 고지

비공식 팬 제작 학습 도구입니다. Pokémon, Nintendo, Creatures, GAME FREAK, DeNA 및 GameWith·Limitless와 제휴 관계가 없습니다. 카드 이미지·로고·HTML·기사 원문·전체 번역은 포함하지 않습니다. 카드 이름과 최소 식별 정보·실제 수량만 기록합니다.

- 실제 제출 목록: 각 덱의 Limitless 원본 링크. API 이용 문서 https://docs.limitlesstcg.com/developer/tournaments / 이용 조건 https://limitlesstcg.com/legal
- 자료 확인일: 기존 7개 2026-10-30 / 신규 3개 2026-11-18. 과제용 최초 선별일: 2026-11-16. 날짜 갱신으로 자료가 최신이라고 간주하지 않습니다.
- 운영·강점·주의점: 정확한 버전의 카드 자료를 참고한 직접 작성 제안. 실전 승률·최적 수순·티어 미검증.
- 커뮤니티 식별 정보: https://github.com/flibustier/pokemon-tcg-pocket-database/tree/746566d75408c04fe35210c503351dc87aee00c5 에서 유래한 최소 식별 필드가 포함돼 아래 고지를 보존합니다. 이미지 권한을 뜻하지 않습니다.
